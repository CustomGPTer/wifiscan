# WiFi Scan

WiFi Scan is a free Android WiFi analyser: speed test, signal and channel ratings, every device on your WiFi, a router security check, heatmaps, scheduled tests with alerts and PDF reports. It tells you why your WiFi is slow and how to fix it. No adverts, no account.
